\# Unified Business Hub – Project Notes



\## Project Organization



\- `docs/` – Project documentation and interface sketches.

\- `frontend/` – User interface and dashboard.

\- `backend/` – Python application, APIs, and business logic.

\- `database/` – Database models and configuration.

\- `tests/` – Application tests.

\- `requirements.txt` – Python dependencies.

\- `README.md` – Project overview and status.



\## Coding Standards



\- Use Python and follow PEP 8 coding standards.

\- Use descriptive names for variables and functions.

\- Keep code simple, readable, and organized.

\- Add comments when necessary.

\- Use consistent file and folder naming.

\- Test new features before committing changes.



\## Instructions for Claude Code



Claude Code may assist with developing, reviewing, and debugging the application.



Claude Code must never:



\- Delete files without permission.

\- Modify unrelated files.

\- Change the project's main objectives without approval.

\- Overwrite working code without permission.

\- Store passwords, API keys, or credentials in source code.

\- Install new dependencies without approval.

\- Commit or push changes to GitHub without permission.



\## Development Workflow



1\. Review the assigned GitHub issue.

2\. Plan the changes before writing code.

3\. Develop one feature at a time.

4\. Test the feature.

5\. Update documentation when necessary.

6\. Commit completed changes with descriptive messages.
